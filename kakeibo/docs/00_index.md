# kakeibo 設計書

家計簿アプリ(`kakeibo`)の設計ドキュメント一式です。
このアプリを初めて引き継ぐ人が、これらのドキュメントだけを読んで「なぜこう作ったか」を理解し、
環境構築からコードの変更まで一人で行えることを目標にしています。

## ドキュメント構成

| ドキュメント | 内容 |
|---|---|
| [01_requirements.md](./01_requirements.md) | 要件定義書。何のために・誰のために・何を作るかを定義 |
| [02_basic-design.md](./02_basic-design.md) | 基本設計書。システム構成・画面・データベースの全体像を定義 |
| [03_detailed-design.md](./03_detailed-design.md) | 詳細設計書。画面・処理・テーブルの詳細仕様を定義 |
| [04_environment-setup.md](./04_environment-setup.md) | 環境構築手順書。Supabase / Vercelのセットアップ手順とトラブルシューティング |

## 読む順番の目安

- **これから初めて環境を作る人** → `04_environment-setup.md` から読む
- **仕様を理解してから改修したい人** → `01` → `02` → `03` の順に読む
- **とにかく動かして触りながら理解したい人** → `04` で動かしてから `02`・`03` を必要な箇所だけ読む

## 開発の背景

このアプリは、Anthropic社のAIアシスタント「Claude」(Claude Code)を使って、
チャットでの指示のみで開発されました。設計書自体もClaudeが作成していますが、
内容は実際に動作しているコードに基づいており、人が読んでそのまま開発・保守できることを前提に書いています。

なお、初期バージョンにはSupabaseのメールログイン機能がありましたが、個人1人での利用に限定したため
ログイン機能自体を廃止しています(詳細は[01_requirements.md](./01_requirements.md)の「変更履歴」を参照)。

コード本体については [../README.md](../README.md) も参照してください(セットアップ手順の要約はそちらにもあります)。
