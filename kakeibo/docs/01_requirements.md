# 要件定義書

## 1. システム概要

### 1.1 目的

日常の収入・支出を記録し、月ごとの収支とカテゴリ別の内訳をひと目で確認できる家計簿アプリを提供する。
あわせて、記録の追加・編集・削除に応じてデータベースがどう動くか(CRUD・集計・トリガーによる自動ログ)が
画面上で見える作りにし、データベースの仕組みを学ぶ題材としても使えるようにする。

### 1.2 背景

日常生活で継続的に使えて、かつ裏側のデータベースの動きが分かりやすい題材として企画した。
家計簿は「記録する(INSERT)」「直す(UPDATE)」「消す(DELETE)」「月ごとに集計する(JOIN + GROUP BY)」という
データベースの基本操作が自然に発生するため、学習用の題材に適している。

### 1.3 想定利用者

- 開発者本人のみ(個人利用)。複数人での利用は想定しない

## 2. 機能要件

| # | 機能 | 概要 |
|---|---|---|
| F1 | 収支の記録 | 日付・種別(収入/支出)・カテゴリ・金額・メモを指定して記録を追加する |
| F2 | 収支の編集・削除 | 記録済みの内容を後から修正・削除する |
| F3 | 月の切り替え | 前月・翌月に表示を切り替えて、その月の記録だけを見る |
| F4 | 月次サマリー | 表示中の月の、収入合計・支出合計・収支(差額)を表示する |
| F5 | カテゴリ別内訳 | 表示中の月について、カテゴリごとの合計金額を棒グラフで表示する |
| F6 | カテゴリの追加 | 収入・支出それぞれに、独自のカテゴリを追加できる |
| F7 | データベース操作ログ | 記録の追加・更新・削除が行われるたびに、データベース側で自動生成される操作ログを一覧表示する |

### 2.1 対象外(スコープ外)とする機能

- ログイン・ユーザーごとのデータ分離(個人1人での利用に限定するため、意図的に持たない)
- カテゴリの編集・削除(追加のみ)
- 複数月・複数年をまたいだ推移グラフ
- 予算(月ごとの上限額)の設定・超過警告

## 3. 非機能要件

### 3.1 コスト

- 個人利用の規模で、原則として**無料**で運用できること(Vercel Hobby + Supabase Free)

### 3.2 可用性

- 24時間365日の稼働を保証する必要はない(個人利用のため)
- Supabase無料プランの制約により、1週間アクセスが無いとデータベースが自動的に一時停止する場合がある
  (手動で再開可能、データは消えない)

### 3.3 セキュリティ

- ログイン機能を持たないため、**デプロイ後のURLとSupabaseのanonキーを知っていれば誰でも記録を閲覧・編集・削除できる**
  ことを明確な制約として受け入れる
- 上記を許容できない場合は、Vercelの「Deployment Protection(パスワード保護)」で
  サイト全体にアクセス制限を掛けることを推奨する(自作のログイン画面は持たない)
- データベースへの書き込みは、行レベルセキュリティ(RLS)を有効にした上で「anonロールに許可」というポリシーにする
  (RLSを無効化するのではなく、意図的に開いた状態にすることで、将来ログインを復活させる際の拡張性を残す)

### 3.4 保守性

- 将来別の人が見ても分かるよう、設計書・READMEを整備すること(本ドキュメント一式がその対応)
- 環境構築に必要な手順・設定値をすべて文書化すること

## 4. 制約条件

- 開発・運用に使うサービスはすべて無料プラン(個人が新規にアカウントを作る前提)で完結させること
- 開発はClaude(AIアシスタント)による支援を受けながら、非エンジニアのオーナーが指示を出す形で行う
  - そのため、環境構築や設定変更の手順は、専門用語を避け、画面のどこを操作するかが分かるレベルまで具体的に記載すること

## 5. 用語集

| 用語 | 説明 |
|---|---|
| RLS(Row Level Security) | データベースの行(レコード)単位でアクセス制御を行う仕組み。Supabase(PostgreSQL)の機能 |
| anonキー / anonロール | ログインしていない状態でSupabaseにアクセスする際に使われる、公開しても問題ない前提のキー・権限 |
| トリガー | テーブルへのINSERT/UPDATE/DELETEなど、特定の操作をきっかけに自動実行されるデータベース側の処理 |
| RPC関数 | データベース側に定義した処理(SQL関数)を、アプリから直接呼び出す仕組み。Supabaseでは`supabase.rpc(...)`で呼び出す |
