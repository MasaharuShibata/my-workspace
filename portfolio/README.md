# portfolio

転職活動用の職務経歴書 / ポートフォリオサイトのテンプレートです。
サイドバーにプロフィール、メインエリアに職務経歴・スキル・実績・学歴をまとめる構成になっています。

## 構成

- `index.html` : ページ本体(プロフィール、職務経歴、スキル、実績、学歴・資格)
- `style.css` : デザイン(紙・雑誌のようなエディトリアル系スタイル、印刷対応)
- `script.js` : 現在年の表示、印刷ボタンの制御

## 使い方

1. `index.html` 内のサンプルテキスト(氏名・会社名・経歴など)を自分の内容に書き換える
2. ブラウザで `index.html` を開いて表示を確認する
3. サイドバー下部の「この経歴書を印刷 / PDF保存」ボタンから、印刷またはPDF保存ができる(印刷用のレイアウトを別途用意済み)

## カスタマイズのポイント

- 配色やアクセントカラーは `style.css` の `:root` 内の変数(`--color-accent` など)でまとめて変更できる
- `#career` の `.timeline-item` を増減すれば、職務経歴の項目数を調整できる
- `#skills` の `.skills-group` や `#projects` の `.project-card` も同様にブロック単位で増減可能
