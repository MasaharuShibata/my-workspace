# calculator

シンプルな電卓Webアプリです。四則演算・パーセント計算・小数点入力に対応しています。

## 構成

- `index.html` : ページ本体
- `style.css` : デザイン(iOS風のダークテーマ、丸ボタン)
- `script.js` : 計算ロジック・キー入力処理

## 使い方

ブラウザで `index.html` を開くだけで利用できます。画面のボタンタップのほか、キーボードにも対応しています。

- 数字キー・`.` : 数値入力
- `+` `-` `*` `/` : 四則演算
- `Enter` または `=` : 計算実行
- `Backspace` : 1文字削除
- `Escape` : クリア
- `%` : パーセント計算(入力値を100で割る)
