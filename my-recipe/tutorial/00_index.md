# my-recipe 開発教材 — Webアプリをゼロから作る

このディレクトリは、`my-recipe`(食材を入力するとAIがレシピを考案するWebアプリ)を
**完成品ではなく「作る過程」から学ぶ**ための教材です。

`docs/` に置いてある設計書が「完成したアプリの仕様書」だとすれば、
こちらは「その仕様書とコードに、初心者が自力でたどり着くための道案内」です。

---

## この教材の対象

- Webアプリを作ったことがない
- HTML / CSS / JavaScript / TypeScript が何なのか、区別がついていない
- 「サーバー」「データベース」「API」といった言葉を、雰囲気でしか理解していない
- プログラミング経験は、ほぼゼロか、学校で少し触った程度

つまり **完全な初心者** を想定しています。
逆に、すでにReactやNext.jsを書いたことがある人には冗長です。Part 3 から読んでください。

## この教材のゴール

読み終えたとき、次の状態になっていることを目指します。

1. `my-recipe` と同じものを、**手元で一から打ち込んで動かせる**
2. 各行が「なぜそう書いてあるのか」を説明できる
3. 別の題材(例: 読書記録アプリ)を、**同じ手順の型で自分で設計・実装できる**

3 が本当のゴールです。写経して動いた、で終わらせないために、
各章の終わりに「自分で考える」という節を置いています。

---

## 大事な前提 — 「何から作り始めるか」という問い

初心者がまず詰まるのは、文法ではなく **順番** です。
真っ白なフォルダを前にして「で、何から書けばいいの?」で止まります。

この教材の骨格は、その答えを一本の線にしたものです。

```
① 何を作るか決める      → 要件定義
② どういう部品で作るか決める → 基本設計
③ 部品の中身を決める     → 詳細設計
④ 見た目だけ作る        → 動かないHTMLの画面
⑤ 画面を動かす         → ボタンを押すと反応する
⑥ 偽のデータで繋ぐ      → サーバー側の処理をダミーで作る
⑦ 本物に差し替える      → AI・データベースに繋ぐ
⑧ 公開する           → デプロイ
⑨ 壊れていないか確認する  → 試験
```

ポイントは **④〜⑦の並び** です。
初心者がやりがちな失敗は、いきなり「AIに繋ぐ処理」から書き始めて、
画面もデータの形も決まっていないまま迷子になることです。

この教材では徹底して **「外側(目に見えるところ)から内側(サーバー・DB)へ」**、
そして **「偽物で通してから本物に差し替える」** という順で進みます。

## 進め方の目安

一気に読もうとすると必ず挫折します。以下のペースを推奨します。

| 期間 | 範囲 | 状態 |
|---|---|---|
| 1日目 | Part 0(01〜02) | 全体像がぼんやり分かる。環境が動く |
| 2〜4日目 | Part 1(03〜07) | 写経レベルで文法が読める |
| 5日目 | Part 2(08) | 設計書の意味が分かる |
| 6〜12日目 | Part 3(09〜17) | アプリが手元で動く |
| 13〜14日目 | Part 4(18〜21) | 公開されて、人に見せられる |
| 15日目 | Part 5(22〜24) | 使っているサービスの中身が分かる |
| 随時 | Part 6(25) | 商用化を検討するときに読む |

**Part 5 は、Part 0〜4 のどこで読んでも構いません。**
「なぜpushしたら公開されるのか」「サービス同士はどう繋がっているのか」が
気になったら、その時点で 22〜24章 に寄り道してください。
むしろ、一度手を動かした後のほうが腹に落ちます。

**Part 1 を完璧にしてから Part 3 に行こうとしないでください。**
文法は、使う場面に出会って初めて定着します。Part 1 は「7割わかった」で先に進み、
Part 3 で詰まったら戻ってくる、という往復が一番早いです。

## 教材内の表記ルール

- `ターミナル` と書かれたコードブロックは、コマンドを打つ場所です
- `ファイル名: app/page.tsx` のように、どのファイルの話かを必ず明示します
- 💡 は「知らなくても動くが、知っていると理解が深まる」補足です
- ⚠️ は「ここを間違えると詰まる/危険」という警告です
- 🖐 は「手を止めて自分で考える」演習です

## 完成品の場所

答えは同じリポジトリの中にあります。

- ソースコード: `my-recipe/` 直下(`app/` `components/` `lib/` など)
- 設計書: `my-recipe/docs/`

詰まったら見て構いません。ただし **「見る前に5分は自分で考える」** を守ってください。
その5分が、写経と理解の分かれ目です。
