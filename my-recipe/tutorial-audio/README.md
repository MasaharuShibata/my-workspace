# my-recipe 開発教材 音声版

`my-recipe/tutorial/` に置いてある開発教材を、**耳だけで聴いて理解できる形**に
書き直したものです。iPhone などの読み上げアプリに入れて、通勤中や家事の合間に
聴くことを想定しています。

伝えている内容は本編と同じです。省略はしていません。
違うのは「目で追う前提の表現」を、すべて「耳で追える表現」に置き換えている点です。

---

## 本編との違い

| | 本編(tutorial/) | 音声版(このディレクトリ) |
|---|---|---|
| 想定 | 画面を見ながら手を動かす | 聴くだけ。手は空いていない |
| コード | そのまま掲載 | 掲載しない。何をする処理かを言葉で説明 |
| 図・表 | 図解と表 | 文章で言い換え |
| 記号 | `NEXT_PUBLIC_` のように原文表記 | 「ネクスト、アンダーバー、パブリック」と読みを添える |
| 章の長さ | 読み飛ばし前提 | 頭から終わりまで通して聴ける流れ |

## 聴きながら学ぶときの進め方

1. まず音声版で1章を通して聴く。分からない部分があっても止めない
2. 手を動かせるときに、本編の同じ番号の章を開く
3. 本編で写経する。音声版で聴いた「なぜ」が思い出せれば成功

音声版だけでアプリが完成することはありません。
**音声版は「理解の下地」、本編は「実際に作る手順書」** という役割分担です。

ただし Part 0(1章・2章)、Part 2(8章)、Part 5(22章から24章)、Part 6(25章)は
考え方の話が中心なので、音声版だけでもほぼ内容を持ち帰れます。

## 表記について

読み上げアプリが記号をそのまま読んでしまうことを避けるため、
音声版のファイルでは次のルールを守っています。

- 見出し以外にマークダウン記号を使わない(太字、コードの囲み、箇条書き記号、表、リンクを使わない)
- 英単語の用語は、初めて出てきたときにカタカナの読みを添える
- 記号を含む名前は、記号の呼び方を言葉で説明する
- 番号付きの手順は「1つめ」「2つめ」のように文章の中で数える

もし使っているアプリが見出しの記号まで読み上げてしまう場合は、
アプリ側の設定でマークダウンの装飾を無視する設定を探してみてください。
